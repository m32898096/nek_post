## 表格契約

P = machine paths configuration；K = scientific cases configuration；H = h-study configuration。L = scientific case label；C = resolved case-directory basename；F = native frame directory。labels 與 basename 不可互換。D = direct complete workflow API；A = new workflow adapter joining existing operations；S = installed subprocess orchestrator。A/S 都是未來新增層；現有 delegate 欄只列實際存在的函式，並非宣稱該單一函式完成全部輸入、輸出或 CLI orchestration。

每列的 scientific inputs/configuration 與獨立的 Filesystem safety 欄分開。**FS = mandatory Filesystem Safety Context**：所有 46 writing leaves（含 installed dry-run）必須由 `--paths-config` 或 `NEK_POST_PATHS_CONFIG` resolve 完整 machine/input inventory，在任何 R/.cli allocation 或 write-capable handler import 前通過 safety preflight；沒有 machine-specific fallback，缺失/不完整則 unavailable。這適用於 42、43 catalog build、44 preview/publish 與 Extra，即使 scientific configuration 不需 P。**RO = no writing safety context**：三個 read-only leaves 零 allocation，仍需該列 scientific configuration；help/plan 另維持 zero-write。完整角色/順序見 [Filesystem Safety Context](configuration_dependencies.md#mandatory-filesystem-safety-context)。

每列 scientific options/defaults/argparse 契約仍以連結的 legacy entrypoint 為準，不透過新命令更改。完整 outputs/side effects 見同 command key 的 [destination contracts](destination_contracts.md)。prerequisites 見 [configuration/dependencies](configuration_dependencies.md)；所有 future tests 尚未執行。批次、review/rollback 見 [roadmap](implementation_roadmap.md)。

`plot*` 表示輸出選項可能省略 plots，但 legacy eager imports 可能仍需要 Plot profile；`vtk*` 表示選定 export/readback 功能需要 VTK。實作前按 capability 確認，不能由 no-plots 自動推斷可移除 eager dependency。

## Legacy 保留與特殊 split

所有 46 個原檔案與 implementation 在 Phase 4 保留不變：路徑、globals、aliases、argparse、side effects、output schemas、skip/overwrite/error 行為都需 characterization。不是把舊檔換成 facade。

- 37 的 legacy main 仍呼叫 publication API；新 validate leaf 使用 `validate_omega_x_production`，新 publish leaf 使用 `build_omega_x_series_pvd`。
- 43 拆成 read-only inventory 與 writing catalog build。
- 44 拆成 writing preview 與 narrowly authorized publish。
- 三次一對二增加 3 leaves，故 46 → 49。
- `integrate gll-field`（22）是獨立 directional scalar capability，不併入 Cantero。
- `front history` 是外部 front histories；`front concentration` 是濃度推導，不能交叉替換。
- `leading-edge plot-refined` 是未編號的 N7 script；與 32 的 H-case native-coordinate plotting 分開。

Benchmark 的 proposed exact override/argv/filenames 以 [M1 handshake](target_architecture.md#exact-benchmark-child-output-handshake-m1) 為準：一般 extraction destination 只在沒有 `--output-dir D` 時使用；有 override 時 D 必須位於 parent R 之內，direct CSV readback 與 legacy defaults 不變。
