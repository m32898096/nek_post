## Common batch contract

每批開始前確認 separately authorized branch/HEAD/clean state，保存 G-FREEZE source bytes/hashes 與 native baseline contracts。所有 25 protected sources、額外 vtu_compat.py、原有 46 legacy implementations/paths 均排除於修改範圍；不能以搬檔或 wrapper 變更其 globals/identity。C12 僅可在另行授權後 additive 修改 **unprotected** leading_edge_benchmark.py，不動 protected kernels。Native `__file__` guards 不得繞過。

每批 **before**：source/AST/interface/output-path characterization、既有相關 tests baseline、代表性 isolated fixtures；**after**：該批下列專項 checks，加 G-HELP/G-CONFIG（適用者）/G-WRITE/G-LEGACY/G-FREEZE、appropriate numerical/schema tests。Tests 不得覆寫 production/goldens 或用新實作反算 reference。每批需獨立完整 diff review、明確 pass/remaining gates 後才能進下一個相依批次；這些都是未來 implementation task 的驗收要求。

Rollback boundary：只撤回/停用該批新增 handler/registry route 及已明確授權的相關 metadata/code changes；保留全部 legacy 路徑、先前已接受批次、native scientific data/staging/logs。未提交時只處理已確認本批 diff；已提交/發布需另行批准 revert。不得 reset/clean scientific outputs、修改 native metadata 或以放寬 resume 消除失敗。
